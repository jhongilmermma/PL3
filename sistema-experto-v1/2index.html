¿Cómo funciona el sistema?

Motor de inferencia

El sistema utiliza un algoritmo de puntuación ponderada que evalúa cada síntoma y le asigna un peso según su relevancia para cada enfermedad. La suma de estos pesos determina la probabilidad de cada diagnóstico.

Base de conocimientos

La base de conocimientos contiene reglas que relacionan síntomas con enfermedades, así como tratamientos asociados a cada diagnóstico. Fue construida a partir de 500+ historias clínicas del Policlínico Monserrat.

Aprendizaje del sistema

Este sistema está diseñado para aprender de nuevos casos. Cada diagnóstico realizado puede ser validado por un médico especialista, permitiendo ajustar los pesos de las reglas y mejorar la precisión del sistema con el tiempo.
