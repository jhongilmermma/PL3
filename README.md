Bienvenido al repositorio oficial de laboratorios, aplicaciones web, algoritmos y sistemas desarrollados durante el curso de **Lenguaje de Programación III**. Este repositorio contiene una colección estructurada de 29 proyectos interactivos que abarcan desarrollo web frontend, algoritmos de toma de decisiones, lógica condicional, simulación de procesos, análisis de datos y fundamentos de IA.

## 🛠️ Instalación y Uso Local

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/jhongilmermma/lenguaje-de-programacion-3.git
   cd lenguaje-de-programacion-3
   ```

2. **Ejecutar cualquier proyecto:**
   Cada carpeta de proyecto es independiente. Puedes abrir directamente el archivo `index.html` en tu navegador web preferido o utilizar una extensión como **Live Server** en VS Code.
